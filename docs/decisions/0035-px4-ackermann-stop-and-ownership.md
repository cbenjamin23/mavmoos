# 0035 — PX4 Ackermann motion, stop and mission ownership

November 6, 2026. Select a distinct `px4_rover_control` provider for ground steering, native Rover mission actions and the shared planar helm adapter. Aircraft remain in `px4_control`. PX4 advertises the same underlying autopilot family, and the Ackermann geometry, positive-speed course envelope and stopped handback differ from both aircraft and ArduRover. Keep the selected profile, verified airframe and FC loss settings in the authorization check. Use stock pHelmIvP course and speed without changes. [Operator contract](../plugins/px4_rover_control.md) · [Acceptance plan](../plans/2026-11-06-px4-ackermann/README.md)

PX4 v1.17.0 SIH Ackermann accepts horizontal velocity in local NED through the normal MAVLink receiver when external setpoint forwarding is enabled. An admitted request prestreams zero velocity, observes Offboard, and streams only currently eligible helm intent. The host owns expiry and cancellation. Withdrawal delegates fallback to PX4 native Hold. Active Hold and retained Offboard intent can coexist. A fresh grant requires independently verified active and intended Hold and a new stationary dwell. [Pinned receiver](https://github.com/PX4/PX4-Autopilot/blob/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/src/modules/mavlink/mavlink_receiver.cpp#L1034-L1268)

Use a quality-gated raw GNSS dwell for stationarity. The initial interface study showed estimator velocity drift while SIH ground truth was stopped. PX4 generates `GPS_RAW_INT` from `sensor_gps`, with independent speed and horizontal-accuracy fields. Bound report age, speed, position excursion and accuracy. Require advancing local and firmware time. Qualify the chosen thresholds against SIH ground truth and preserve the receiver’s reported uncertainty in the record. [Pinned GPS stream](https://github.com/PX4/PX4-Autopilot/blob/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/src/modules/mavlink/streams/GPS_RAW_INT.hpp#L59-L97)

Separate mission storage from execution. Bind verified readback, the current opaque PX4 plan ID, original deadline and exclusive motion lease. Persist the host's uncertainty marker before start. Pause and release rely on current Hold and stopped evidence. Abort can make a bounded stop-only request when the selected FC still permits it. A restart observes the existing FC state, preserves the fence, and requires explicit handback in the current process session. Onboard Mission can continue without the bridge.

Use MAVROS for the protocol pattern. Its command path scopes a waiter to a command and waits within a bounded interval. Its mode service exposes `mode_sent`, and its mission transfer retries are bounded to the current transfer phase. MAVMOOS also needs an explicit, observed vehicle effect before changing helm authority. A send, a command ACK, an exact mission readback and confirmed stop each answer separate questions. A timeout retires local work and may leave the remote effect unresolved. The compatible release and model, motion envelope, tests and limitations are recorded in the qualification ledger. Differential and mecanum layouts need separate policy and evidence for steering and handback. Richer Rover setpoint types need a separately qualified transport and wire interface.
