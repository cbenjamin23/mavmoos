# ArduSub control

Select `vehicle_profile=ardusub` with the `ardusub_control` provider. This profile owns stock helm guidance, a captured Guided hold, and explicit native Position Hold and Surface handbacks. It enables control only in the dedicated owned loopback SITL composition with `plugins=telemetry,ardusub_control`, `control_helm=true`, `control_native_actions=false`, and `firmware_requests=false`. The fixture uses the upstream vectored hull and simulated absolute horizontal positioning. The FC owns thruster mixing, attitude, and velocity tracking. The independent fixture operator establishes armed Position Hold before requesting helm control.

| Operator intent | MOOS request | Expected result |
| --- | --- | --- |
| Give navigation to the helm | `MAVMOOS_NAV_CONTROL=acquire` | From armed Position Hold 16, request Guided 4 once. Confirm with a new FC heartbeat after the mode command reaches the socket. Accept only a new stock helm tuple after that confirmation. |
| Release the helm | `MAVMOOS_NAV_CONTROL=release` | Cancel pending movement and attempt one captured-position hold while fresh evidence still supports Guided. |
| Return to native position control | `MAVMOOS_SUB_HANDBACK=hold` | Retire the helm grant and request native Position Hold 16. `MAVMOOS_SUB_HANDBACK_RESULT` reports queueing, socket acceptance, and confirmation from a fresh FC heartbeat separately. |
| Surface | `MAVMOOS_SUB_HANDBACK=surface` | From eligible submerged Guided, Position Hold or Depth Hold, retire helm permission and request native Surface 9. Confirm Surface from fresh heartbeat, then independently require shallow Depth Hold 2 depth at most 0.35 m with the settled observation window. |

Surface is a single bounded handback with exact origin mode and fresh depth, position and sensor evidence. A Manual takeover, expired request or lost prerequisite fences the final send. Surface retains native authority after handback. A separate acquisition requires a new eligible native Position Hold and fresh helm intent.

The stock helm uses its ordinary course, speed, and depth domains and publishes `DESIRED_HEADING`, `DESIRED_SPEED`, and `DESIRED_DEPTH`. Course is clockwise from true north. Horizontal speed is 0–1 m/s. Depth is 0–8 m, positive down from the FC's bound home surface. The adapter requires fresh `DRIVE` and clear all-stop evidence. The grouped scalar decision retains original MOOS timestamps and the freshness and spread bounds. `ARRIVAL_GROUPED` describes this stock-helm evidence.

`NAV_DEPTH` and the provider use the same reference. Subtract `GLOBAL_POSITION_INT.alt` in MSL millimetres from `HOME_POSITION.altitude` in MSL millimetres and express the result in metres. The fixture initializes the modeled surface at MSL zero and uses the FC’s bound home near that surface as its depth datum. `NAV_DEPTH_VALID` describes the position and home projection. The control provider separately requires a fresh healthy absolute pressure sensor and a valid absolute estimator. The profile rejects expired, unhealthy, or out-of-envelope observations. `MAVMOOS_SUB_STATUS` exposes readiness, pressure health, and `depth_reference=FC_HOME_SURFACE_MSL`. Shadow mode reports `MAVMOOS_SHADOW_DEPTH` along with course and speed. The pinned Sub source calculates the wire relative-altitude field using EKF origin depth, so the profile derives depth from the two absolute altitude fields. [Pinned Sub altitude projection](https://github.com/ArduPilot/ardupilot/blob/92b0cd788ec29406f26c6f9c31d5ceedbd1cc538/ArduSub/GCS_Mavlink.cpp#L916-L921)

The provider sends `SET_POSITION_TARGET_LOCAL_NED` with horizontal velocity projected from course and speed. The depth correction is 0.6 times the depth error, bounded to 0.4 m/s up or down. Yaw tracks course above 0.08 m/s. The captured hold sends a position-only `SET_POSITION_TARGET_LOCAL_NED` in `LOCAL_OFFSET_NED` with zero offsets. The FC captures its current horizontal position and depth at receipt. The pinned local handler rejects the target in native Depth Hold, whose depth target can be changed by the global setpoint handler. Guided remains the FC mode for captured hold. Native Position Hold owns its own position target after handback. [Pinned Guided controller](https://github.com/ArduPilot/ardupilot/blob/92b0cd788ec29406f26c6f9c31d5ceedbd1cc538/ArduSub/mode_guided.cpp) · [Pinned native Position Hold](https://github.com/ArduPilot/ardupilot/blob/92b0cd788ec29406f26c6f9c31d5ceedbd1cc538/ArduSub/mode_poshold.cpp)

A short ordinary no-goal transition can resume with a new valid tuple inside the configured handoff window and while FC Guided evidence remains current. Helm silence or an invalid prerequisite retires the grant. Native mode takeover requires new explicit acquisition. The owned simulator independently sets `FS_GCS_ENABLE=3` and `FS_GCS_TIMEOUT=2.5` for the bridge system ID. ArduSub owns the Depth Hold response to loss of those heartbeats. [Pinned GCS failsafe](https://github.com/ArduPilot/ardupilot/blob/92b0cd788ec29406f26c6f9c31d5ceedbd1cc538/ArduSub/failsafe.cpp#L321-L359)
