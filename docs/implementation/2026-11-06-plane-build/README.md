# ArduPlane 4.6.3 build reference

The Plane control tests use an offline macOS ARM64 build of ArduPlane 4.6.3. The [build manifest](manifest.json) records the exact source, submodule pins and executable checksum. This record covers compilation and artifact verification. The [Plane test guide](../../../tests/plane_native/README.md) describes how to run the simulator workflows.
