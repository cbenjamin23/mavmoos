Get started

Build MAVMOOS from source and check that vehicle telemetry reaches MOOS.

1. Build

Put the bin/ directory from your built MOOS-IvP checkout on PATH. Then clone MAVMOOS and build it.

git clone https://github.com/cbenjamin23/mavmoos.git
cd mavmoos
./build.sh

[[setup_guide]] if you need MOOS-IvP or the build tools.

2. Verify telemetry

ctest --test-dir build -R '^moos_normal$' --output-on-failure --no-tests=error

A pass means a local test sender reached MOOS and MAVMOOS sent no MAVLink frames. The test starts and stops its own processes.

3. Try a simulated mission

The [[copter_starter]] runs a short IvP Helm route through takeoff, guidance handback and landing on Apple Silicon macOS.
